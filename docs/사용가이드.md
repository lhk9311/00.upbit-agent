# 업비트 에이전트 사용 가이드

> 처음 써보는 사람을 위한 안내서. 주식·코인을 잘 몰라도 따라올 수 있게 썼다.

## 한 줄 요약

**"이런 조건의 코인을 찾아서, 찾으면 사고, 몇 % 오르거나 내리면 팔아줘"를 정해두면, 프로그램이 1분마다 알아서 가짜 돈으로 사고팔아 보는 서비스.**

- 실제 돈은 쓰지 않는다 (모의매매).
- 결과를 보고 "이 조건이 쓸만한가?"를 판단하는 게 목적이다.

---

## 1. 꼭 알아야 할 개념 5가지

이 서비스에서 쓰는 주식 용어는 이게 전부다.

| 용어 | 뜻 | 이 서비스에서 |
|---|---|---|
| **캔들(봉)** | 일정 시간 동안의 가격을 막대 하나로 표시. 시작가·최고가·최저가·끝 가격 4개 정보 | 차트의 빨간·파란 막대. "1시간봉" = 막대 하나가 1시간 |
| **이동평균선 (MA)** | 최근 N개 봉의 평균 가격. MA20 = 최근 20봉 평균 | **정배열**(MA5 > MA20 > MA60) = 최근일수록 평균이 높음 = 오르는 중 |
| **RSI** | 최근에 얼마나 많이 올랐는지를 0~100으로 표시 | 70 이상 = 많이 오름(과열), 30 이하 = 많이 떨어짐(과매도) |
| **거래량 급증** | 평소보다 갑자기 많이 거래됨. 뭔가 일이 생겼다는 신호 | "거래량 3배" = 직전 봉 거래량이 평소 20봉 평균의 3배 이상 |
| **익절 / 손절 / 수수료** | 익절 = 올랐을 때 팔아 이익 확정, 손절 = 떨어졌을 때 팔아 손실 제한. 수수료 = 거래할 때마다 떼이는 돈 | 익절 +5%, 손절 -3% 같은 규칙. **사고팔면 수수료+체결 손해로 약 0.3%가 빠지므로 0.3% 이상 올라야 본전** |

색깔 규칙: 한국 관례대로 **상승·수익은 빨강, 하락·손실은 파랑**이다.

## 2. 전체 흐름

```
① 종목 검색      조건을 고르면 → 지금 조건에 맞는 코인 최대 10개
       ↓
② 백테스트       "이 조건으로 지난 며칠 했으면 어땠을까?" 미리 확인
       ↓
③ 에이전트 시작   1분마다 조건 검색 → 맞으면 매수 → 규칙에 걸리면 매도 (가짜 돈)
       ↓
④ 에이전트 현황   지금 들고 있는 코인, 평가손익, 활동 기록
       ↓
⑤ 투자 히스토리   지금까지 거래 전체, 수익률, 승률
```

---

## 3. 시작하기

### 실행 (개발자가 한 번 해두면 됨)

1. 백엔드 서버 실행 (IntelliJ에서 `UpbitAgentApplication`)
2. 프론트 실행: `frontend` 폴더에서 `npm run dev`
3. 브라우저에서 http://localhost:5173 접속

### 로그인

- 아이디: `admin`
- 비밀번호: 서버를 **처음** 켰을 때 콘솔에 한 번 찍힌 값
- 로그인한 뒤 **설정 → 계정**에서 비밀번호를 바꾼다.

서버를 켜고 **1~2분은 시세를 모으는 중**이다. 이때 검색하면 "수집 중" 안내가 뜨는데 정상이다.

## 4. 화면별 사용법

### ① 종목 검색 탭

화면 맨 위에서 조건을 고르고 **검색**을 누른다.

- 처음엔 **프리셋 버튼**(거래량 돌파 / 눌림목 / 과매도 반등)을 눌러보는 게 제일 쉽다.
- 조건은 **전부 동시에 만족**해야 통과한다. 조건을 많이 걸수록 결과가 줄어든다.
- 결과 위에 `전체 301개 → 조건 통과 4개 → 상위 4개`처럼 몇 개가 걸러졌는지 보인다.
- 결과에서 코인을 누르면 오른쪽에 차트가 뜬다.
- 결과가 0개면 조건을 하나 빼거나 숫자를 느슨하게(예: 거래량 3배 → 1.5배) 바꾼다.

> Claude API 키가 설정돼 있으면 맨 위 입력칸에 "거래량 터진 상승 추세 코인"처럼 **문장으로** 조건을 입력할 수도 있다.

### ② 전략 만들기 + 백테스트

검색 결과 아래 **이 조건으로 에이전트 시작 (모의매매)** 를 누르면 설정 창이 뜬다.

| 항목 | 뜻 | 처음 추천 |
|---|---|---|
| 1회 매수 금액 | 한 코인에 얼마씩 살지 | 10,000원 |
| 최대 보유 종목 수 | 동시에 몇 개까지 들고 있을지 | 3개 |
| 익절 +% | 이만큼 오르면 팔기 | 5% |
| 손절 -% | 이만큼 떨어지면 팔기 | 3% |
| 트레일링 -% | 오르다가 최고점에서 이만큼 떨어지면 팔기 (수익 지키기) | 처음엔 비워둠 |
| 최대 보유 시간 | 이 시간이 지나면 무조건 팔기 | 24시간 |
| 일일 손실 한도 | 오늘 이만큼 잃으면 오늘은 그만 사기 | 30,000원 |

**저장하기 전에 백테스트 버튼을 꼭 눌러본다.** 과거 데이터로 돌려본 결과가 나온다.

- **총손익 / 승률**: 이 설정으로 했으면 벌었는지, 몇 번 중 몇 번 이겼는지
- **최대 낙폭**: 가장 많이 잃었던 순간 (얼마나 버텨야 했는지)
- **비트코인 그냥 보유**: 같은 기간 비트코인만 들고 있었으면? → 전략이 이것보다 못하면 굳이 쓸 이유가 없다

만족스러우면 **저장하고 시작**. 이때부터 에이전트가 움직인다.

### ③ 에이전트 현황 탭

- **위쪽 카드 4개**: 지금 들고 있는 코인의 평가손익, 오늘/누적 실현손익, 승률
- **보유 중**: 산 코인, 매수가, 현재가, 지금 팔면 몇 % 인지. **매도** 버튼으로 직접 팔 수도 있다.
- **활동 기록**: 언제 무엇을 샀고 팔았는지. "지금 실행"은 1분을 기다리지 않고 바로 판단시킨다.
- **전략**: 실행 중인 전략 목록. **정지**하면 새로 사지는 않고, 들고 있는 건 규칙대로 계속 판다.

### ④ 투자 히스토리 탭

- 지금까지의 모든 거래. 열 제목을 누르면 정렬된다 (수익률 높은 순 등).
- **완료**된 거래는 매수가·매도가·수익률이 모두 보이고, **진행 중**인 거래는 매수가만 보인다.
- 위쪽 필터로 진행 중/완료, 전략, 기간을 고를 수 있다.

### ⑤ 설정 탭

- **모든 전략 신규 매수 중단**: 비상 스위치. 켜면 모든 전략이 새로 사지 않는다.
- 수수료·모의 체결가 불리·재진입 대기: 모의매매와 백테스트 계산 방식
- 새 전략 기본값: 전략 설정 창에 처음 채워지는 값
- 비밀번호 변경, 시스템 상태 (시세 수집이 잘 되고 있는지)

---

## 5. 따라 해보기 (5분)

1. **종목 검색** → **거래량 돌파** 프리셋 → **검색**
2. 결과가 0개면 거래량 칸을 `1.5`로 바꾸고 다시 검색
3. **이 조건으로 에이전트 시작** → 이름 `첫 전략` → **백테스트** → 결과 확인
4. **저장하고 시작**
5. **에이전트 현황**에서 매수가 생겼는지 확인 (조건에 맞는 코인이 없으면 안 살 수도 있다)
6. 하루 뒤 **투자 히스토리**에서 결과 확인

## 6. 꼭 알아둘 점

- **모의매매다.** 실제 주문은 나가지 않는다. 실제처럼 수수료와 체결가 손해는 반영한다.
- **서버가 켜져 있을 때만 움직인다.** PC를 끄거나 절전 모드면 멈춘다. 그동안 가격이 손절선 아래로 떨어지면, 다시 켰을 때의 가격에 팔게 된다. (그래서 손절 -3%인데 -11%로 팔리는 일이 생길 수 있다)
- **1분마다 판단한다.** 1분 안에 급등락하면 정확히 익절·손절 가격에 팔리지 않을 수 있다.
- **과거 결과가 미래를 보장하지 않는다.** 백테스트가 좋아도 실제로는 다를 수 있다.
- 대부분의 단순한 조건은 수수료를 빼면 수익이 거의 남지 않는다. 결과가 안 좋은 게 정상일 수 있다.

## 7. 자주 묻는 질문

**검색하면 "데이터를 수집하는 중이에요"가 떠요.**
서버를 켠 지 1~2분이 안 됐다. 잠시 기다리면 된다. 15분봉·4시간봉·일봉은 1시간봉보다 조금 더 늦게 준비된다.

**검색 결과가 계속 0개예요.**
조건이 너무 까다롭다. 조건을 하나씩 빼보거나 숫자를 느슨하게 한다.

**전략을 시작했는데 아무것도 안 사요.**
지금 조건에 맞는 코인이 없는 것이다. 활동 기록과 종목 검색 결과를 확인한다. 설정 탭의 "신규 매수 중단"이 켜져 있는지도 본다.

**왜 가격이 그대로인데 -0.30%예요?**
지금 팔면 수수료(0.05%×2)와 체결가 손해(0.1%×2)가 빠지기 때문이다. 0.3% 이상 올라야 본전이다.

**비밀번호를 잊어버렸어요.**
환경변수 `ADMIN_RESET=true`로 서버를 재시작하면 새 비밀번호가 콘솔에 찍힌다. 로그인한 뒤 `ADMIN_RESET`은 다시 끈다.

**서버를 껐다 켜면 기록이 날아가나요?**
아니다. 전략·거래·활동 기록은 DB 파일(`backend/data`)에 저장돼서 그대로 남는다.
